# R71: Split GitOpsPanel.tsx into smaller components

## Problem
`src/components/GitOpsPanel.tsx` is 1472 lines and is a "god component" with too many responsibilities. It needs to be split into smaller, focused components.

## Requirements

### 1. Extract `GitOpsToolbar` component
- Extract all the action buttons (stash, tag, remotes, hooks, submodules, bisect, reflog, conflict resolver, rebase, log, gitignore, stats, patch, clean, reset, archive)
- Should accept callback props for each action toggle
- File: `src/components/GitOpsToolbar.tsx`

### 2. Extract `GitOpsFileList` component
- Extract the file list section that shows changed files with staging controls (stage/unstage, diff, blame, history buttons)
- Should accept files array, staging callbacks, and view callbacks
- File: `src/components/GitOpsFileList.tsx`

### 3. Extract `GitOpsCommitBar` component
- Extract the commit message input area with commit prefix buttons and commit/ai-generate buttons
- File: `src/components/GitOpsCommitBar.tsx`

### 4. Keep GitOpsPanel as orchestrator
- GitOpsPanel stays as the main component but delegates to the 3 new components
- All state management stays in GitOpsPanel
- Lazy-loaded modals stay in GitOpsPanel

### Constraints
- Do NOT change any functionality - this is a pure refactor
- Keep the same interface (GitOpsPanelProps)
- All existing lazy imports stay in GitOpsPanel
- Use memo() for new components
- Keep Chinese UI text as-is
- Maintain existing Tailwind classes exactly
